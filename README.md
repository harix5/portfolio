# Portfolio: Hari Prasath S

Personal portfolio of Hari Prasath S, AI trainer and data quality specialist: LLM evaluation, RLHF, data annotation, and Tamil and English linguistic QA.

The site is plain HTML, CSS and JavaScript, with no build step and no dependencies.

## Sections

- **Welcome:** who I am, the roles I hold now, and links to my work and resume.
- **Experience:** five roles, newest first. Each row opens to the full detail.
- **Skills:** grouped by kind of work, one tab per group.
- **Projects:** a vehicle data visualization dashboard and an industrial object detection pipeline using YOLO.
- **Certificates and education**
- **Resume and profiles:** the resume PDF, LinkedIn and GitHub.
- **Contact**

## Run it locally

Open `index.html` through any static server, for example:

```bash
python -m http.server 5173
```

Then visit `http://localhost:5173`.

## Files

| File | What it holds |
| --- | --- |
| `index.html` | The page content |
| `styles.css` | Layout and components |
| `tokens.css`, `base.css` | Colours, type scale, spacing and base rules |
| `script.js` | Skill tabs, scroll progress, section reveal, copy email, cursor effects |
| `images/` | Background photographs |
| `Hari_Prasath_S_Resume.pdf` | The resume linked from the page |
